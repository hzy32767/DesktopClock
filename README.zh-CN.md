# DesktopClock v1.0

**挂在 Windows 10/11 希沃白板上的教室时钟**——显示当前第几节、上什么课、还有多久下课，一放 PPT 就又自己躲起来。

[English](README.md) · 简体中文 · [纯文本版](README.zh-CN.txt)

`Windows 10/11` · `Python 3.8+` · `MIT` · [github.com/hzy32767/DesktopClock](https://github.com/hzy32767/DesktopClock)

![DesktopClock](docs/screenshot.png)

为中文课堂的希沃（Seewo）交互白板做的，任何 Windows 10/11 电脑都能跑。只用 Python 标准库——没有控制台黑框、不用安装、不写注册表、不联网。

## 能做什么

| | |
| --- | --- |
| **永远在最上层** | `wm_attributes("-topmost", True)` 加 `SetWindowPos(HWND_TOPMOST)` 双保险，每 5 秒巡检一次，被盖住就自己抢回来。 |
| **全屏时自动隐藏** | PPT 放映、全屏视频、希沃授课全屏、锁屏——自动收起来；退出全屏 1.5 秒内回来。 |
| **可拖动** | 按住左键随便拖，坐标夹在屏幕内，拖不出屏幕也丢不了。 |
| **只开一个** | 具名内核互斥体。双击十次也只有一个时钟，后来者安静退出。 |
| **课表热更新** | 改完 `schedule.json`，10 秒内自动生效，不用重启。 |
| **一个文件都不写** | 不落配置、不写注册表、不建临时文件、不开网络连接、不装键盘钩子。 |
| **坏了也不吭声** | 课表缺失或 JSON 坏了，就只显示时间，不弹窗、不崩。 |

卡片是 380 × 72 像素的圆角矩形，1px 描边、纵向渐变、下方柔和阴影。圆角外侧和阴影区是**真透明**的（Win32 分层窗口色键），所以看起来像一张浮着的卡片，而不是一个方形窗口。

## 快速开始

### 方式 A —— 直接运行（不用装 Python）

1. 双击 **`桌面时钟.exe`**。
2. 完成。卡片出现在屏幕正上方居中。

想关掉：在卡片上**点右键 → 退出**。

### 方式 B —— 跑源码

需要 Python 3.8+ 并且带 `tkinter`（官方 Windows 安装包自带）。

```bat
git clone https://github.com/hzy32767/DesktopClock.git
cd DesktopClock
pythonw clock.pyw
```

`.pyw` 由 `pythonw.exe` 承载，不会闪出控制台窗口。

### 运行环境

- Windows 10 / 11，64 位。
- 界面文字是中文（它本来就是给中文课堂用的）。`Microsoft YaHei UI` 是 Windows 10/11 自带的字体，不需要另外装语言包。想要英文星期几，改 `clock.pyw` 顶部的 `DATE_NAMES` 元组即可。

### 文件清单

| 文件 | 是什么 | 需要 Python 吗 |
| --- | --- | --- |
| `桌面时钟.exe` | 时钟本体。**双击这个就行** | **不需要** |
| `转换课表.exe` | 把 `.xlsx` 课表转成 `schedule.json` | **不需要** |
| `开机自启.exe` | 开关开机自启的小面板 | **不需要** |
| `clock.pyw` | 时钟本体（源码版） | 需要 |
| `convert.py` | 转换脚本（源码版），要 `openpyxl` | 需要 |
| `开机自启.pyw` | 自启面板（源码版） | 需要 |
| `转换课表.bat` | 跑 `convert.py` 的小脚本 | 需要 |
| `schedule.json` | 课表数据，时钟只读它 | — |
| `时钟.ico` | 程序图标 | — |

只有 `convert.py` / `转换课表.exe` 用到 `openpyxl`，而且只在转换的那一下用到。

## 卡片长什么样

```
┌──────────────────────────────────────────────┐
│                                              │
│   16:48:29        │  ● 第3节 语文            │
│   星期五           │    距上课 25 分 · 距下课 18 分 │
│  ▬▬▬▬▬▬▬▬▬▬                                  │
└──────────────────────────────────────────────┘
```

| 左栏（55%） | 右栏（45%） |
| --- | --- |
| `HH:MM:SS`，28px 加粗，Segoe UI | 状态圆点 + 状态文字，15px |
| 星期几，12px，Microsoft YaHei UI | 倒计时，11px |

中间一条 1px 竖线，高度是卡片的 60%。

### 状态圆点

| 颜色 | 含义 |
| --- | --- |
| 🟢 `#34C759` | 正在上课——会轻轻"呼吸"（每 800 毫秒换一档明度） |
| 🟠 `#FF9500` | 下一节 30 分钟内开始 |
| ⚪ `#8E8E93` | 课间 / 暂时没课 |

### 底部进度条

2px 的细线，按当前这节课已经过去的比例从左往右填充。**只有真正在上课的时候才出现**——课间、午饭、放学后整条消失。

## 右栏两行是怎么算出来的

两行分别算，互不影响。

**状态行**，严格按优先级：

1. 现在落在**有科目**的时段里 → `第3节 语文`（`第三节` 会规整成 `第3节`）。
2. 现在落在**没有科目**的时段里 → 显示时段名，如 `课间`、`午饭`、`眼保健操`。
3. 都没匹配上，但下一节 30 分钟内开始 → `下节：体育`。
4. 都没匹配上 → `课间休息`。

**倒计时行**——两个独立的小模块，用 `·` 连起来：

| 情况 | 显示 |
| --- | --- |
| 上课中，后面还有课 | `距上课 25 分 · 距下课 18 分` |
| 上课中，当天最后一节 | `距下课 18 分`（居中） |
| 不在上课，知道下一节 | `距上课 8 分`（居中） |
| 今天的课上完了 | `今天没课了` |
| `schedule.json` 缺失或坏了 | *这一行留空，只显示时间* |

分钟**向上取整**，所以 `距下课` 不会出现 `0 分钟`。两个模块塞不进右栏那 144 像素时会逐级降级：`分钟` 压成 `分`，再紧一下空格，实在放不下就只留更相关的那个模块（上课时留"还剩多久下课"，否则留"还有多久上课"）。

## 课表格式

`schedule.json` 是唯一的输入。结构：

```json
{
  "version": "1.0",
  "source": "课程表.xlsx",
  "days": {
    "MON": [
      {"name": "第一节", "start": "08:00", "end": "08:40", "subject": "体育"},
      {"name": "课间",   "start": "08:40", "end": "08:55", "subject": ""}
    ],
    "TUE": [],
    "WED": [],
    "THR": [],
    "FRI": []
  }
}
```

规则：

- 键是 `MON` `TUE` `WED` `THR` `FRI`（想要周末再加上 `SAT` / `SUN`）。
- 时间一律 `HH:MM`，补零。
- `subject` 为空表示"这个时段没课"，**不是**"删掉这个时段"。课间、午饭、眼保健操都要留着——时钟靠这些区间判断当前状态。
- 判断方式就是简单比较 `start <= 现在 < end`。

## 怎么换课表

### 不用装 Python

1. 把新课表存成 `.xlsx`，格式是：

   | 第 1 行 | *（空）* | `MON` | `TUE` | `WED` | `THR` | `FRI` | `时间` |
   | --- | --- | --- | --- | --- | --- | --- | --- |
   | 第 2 行起 | 节次名，如 `第一节` | 科目 | 科目 | 科目 | 科目 | 科目 | `8:00-8:40` |

2. 把文件放到同一个文件夹里（命名成 `课程表.xlsx` 会被自动认出来），或者双击 **`转换课表.exe`** 自己挑。
3. `schedule.json` 会生成在 exe 旁边。正在跑的时钟 10 秒内自动读新的，不用重启。

### 装了 Python

```bat
python convert.py 路径\课程表.xlsx
```

转换是确定性的——同一个工作簿转两次，`schedule.json` 逐字节相同。

### 手改 JSON 也行

完全可以。两个容易踩的坑：

- 时间要补零（写 `08:00`，不要写 `8:00`）。
- 每个时段都要留着，哪怕 `subject` 是空的。

## 开机自启

双击 **`开机自启.exe`**，点一下按钮就行了。

程序**不碰注册表**，只在当前用户的「启动」文件夹里增加 / 删除一个快捷方式：

```
%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup\桌面时钟.lnk
```

也支持命令行：

```bat
开机自启.exe --install    :: 打开
开机自启.exe --remove     :: 关闭
开机自启.exe --status     :: 返回码 0 = 已开启，1 = 未开启
```

> 把文件夹挪了位置之后，记得重新跑一次 `--install`，让快捷方式指向新路径。

时钟本身不会自己在桌面建快捷方式——想要的话自己建（右键 `桌面时钟.exe` → 发送到 → 桌面快捷方式）。**建完之后别再移动或改名程序文件夹**，否则快捷方式会失效。

## 可调参数

所有可调的东西都在 `clock.pyw` 顶部一段「可调参数」里，中文注释写得很清楚。挑几个常改的：

| 常量 | 默认值 | 含义 |
| --- | --- | --- |
| `WIDTH` / `HEIGHT` | `380` / `72` | 卡片宽高（像素） |
| `TOP_MARGIN` | `12` | 距屏幕上边缘 |
| `CORNER_RADIUS` | `16` | 圆角半径 |
| `WINDOW_ALPHA` | `1.0` | 整卡不透明度。`1.0` = 实心，调小会把字也一起变淡 |
| `CHROMA_KEY` | `#FF00FE` | 会被抠成透明的颜色——圆角就是靠它 |
| `BG_TOP` / `BG_BOTTOM` | `#FFFFFF` / `#F8F9FB` | 卡片渐变 |
| `BORDER_COLOR` | `#E8EAED` | 1px 描边 |
| `FG_COLOR` / `MUTED_COLOR` | `#1A1D21` / `#6B7280` | 主要 / 次要文字 |
| `DOT_CLASS_COLOR` | `#34C759` | 上课中的圆点 |
| `DOT_SOON_COLOR` | `#FF9500` | 快上课的圆点 |
| `DOT_REST_COLOR` | `#8E8E93` | 休息的圆点 |
| `BAR_COLOR` / `BAR_HEIGHT` | `#34C759` / `2` | 进度条 |
| `TIME_FONT_PX` | `-28` | 负数 = 按像素，正数 = 磅 |
| `DATE_FONT_PX` / `STATUS_FONT_PX` / `COUNTDOWN_FONT_PX` | `-12` / `-15` / `-11` | 其余字号 |
| `TIME_FONT_FAMILY` | `Segoe UI` | 数字字体 |
| `TEXT_FONT_FAMILY` | `Microsoft YaHei UI` | 中文字体 |
| `DATE_NAMES` | `("星期一", …)` | 星期几的文案——想换语言改这里 |
| `TICK_MS` | `1000` | 时钟刷新间隔 |
| `TOPMOST_POLL_MS` | `5000` | 多久查一次"还在不在最上面" |
| `SCHEDULE_POLL_MS` | `10000` | 多久查一次 `schedule.json` 变没变 |
| `NEXT_CLASS_WINDOW_MIN` | `30` | 「快上课」的提前量，也决定圆点变橙色 |
| `NEXT_CLASS_DURING_BREAK` | `False` | 改成 `True` 时课间优先显示 `下节：X` 而不是时段名 |
| `AUTO_HIDE_ON_FULLSCREEN` | `True` | 全屏时隐藏 |
| `HIDE_POLL_MS` | `1500` | 全屏巡检间隔 |
| `DRAGGABLE` / `DRAG_CURSOR` | `True` / `fleur` | 拖动 |
| `SINGLE_INSTANCE` / `INSTANCE_MUTEX_NAME` | `True` / `Local\DeskClock.SingleInstance.v1` | 只开一个 |

改 `clock.pyw` 只影响源码版。要让打包的 `.exe` 也变，得改完源码重新打包。

## 自己打包 exe

```bat
python -m venv _buildvenv
_buildvenv\Scripts\python.exe -m pip install pyinstaller openpyxl

_buildvenv\Scripts\pyinstaller.exe --noconfirm --clean --onefile --noconsole ^
    --icon 时钟.ico --name DeskClock clock.pyw

_buildvenv\Scripts\pyinstaller.exe --noconfirm --clean --onefile --console ^
    --icon 时钟.ico --name ConvertSchedule convert.py

_buildvenv\Scripts\pyinstaller.exe --noconfirm --clean --onefile --noconsole ^
    --icon 时钟.ico --name Autostart 开机自启.pyw
```

把三个产物改名为 `桌面时钟.exe`、`转换课表.exe`、`开机自启.exe`，和 `schedule.json` 放在一起。

> **踩坑提醒：** PyInstaller 处理不了非 ASCII 的 `--icon` 路径，会把中文名当成相对路径然后报 `FileNotFoundError`。先把 `时钟.ico` 复制成 ASCII 名字（如 `icon.ico`）再传进去。

`.exe` 从**自己所在的那个文件夹**读 `schedule.json`（不是从解压出来的临时目录），所以换课表不用重新打包。

## 关于杀毒软件误报

源码版没什么可疑的：纯标准库、不联网、不写注册表、不装钩子、不自解压。

打包版是另一回事。PyInstaller 单文件模式本身就是个**自解压包**——启动时先把 Python 和 Tk 解压到 `%TEMP%` 再跑。这个特征正好踩在火绒 / 360 / Defender 的启发式规则上，所以**任何** PyInstaller 打包的程序都容易中招，不只是这个。

万一被拦了：

1. 把整个文件夹加进杀软的白名单，或者
2. 改用源码版（`clock.pyw`）——没什么可报的，代价是那台电脑得装 Python，或者
3. 自己打一个 `--onedir` 的文件夹版，它不自解压，被误报的概率低得多。

这个项目不连网、不读别的进程内存、不在自己文件夹之外写任何东西。

## 常见问题

**时钟不见了。**
先看是不是正在放 PPT 或全屏视频——那是它故意藏的，退出全屏 1.5 秒内回来。否则它每 5 秒自检一次置顶状态，被盖住会自己抢回最前面。

**任务管理器里怎么有两个 `桌面时钟.exe`？**
PyInstaller 单文件模式：一个是等待中的解压父进程，一个是真正的子进程。一个时钟 = 两个进程。想确认真的只有一个，看屏幕上卡片有几张——永远是一张。

**能同时开好几个时钟吗？**
不能，故意的。启动时先抢一个具名内核互斥体，抢不到的直接安静退出。锁是内核对象，进程怎么死都会被系统自动释放，不存在"残留锁导致再也打不开"的情况。

**我把它拖到旁边了，怎么又回中间了？**
位置是故意不保存的——这正是程序一个文件都不写的原因。想固定起始位置，改 `_place_window()` 里的 `self.pos_x` / `self.pos_y`。

**任务栏上没有图标。**
对，它是 `overrideredirect` 窗口，本来就不出现在任务栏。判断它在不在跑，看屏幕上方有没有卡片，或者看进程列表。

**整个文件夹拷到别的电脑还能用吗？**
能。文件夹是自包含的，那台电脑不用装 Python。换位置之后记得重建桌面快捷方式，并重跑一次 `开机自启.exe --install`。

**课表里有时间重叠怎么办？**
示例课表就有（眼保健操 14:45–15:50 和第七节 14:50–15:30 重叠）。时钟不擅自改你的数据：多个时段同时命中时，**有科目的那个**优先，所以 14:50–15:30 会正确显示 `第7节 语文`。想彻底干净就去改源表格。
