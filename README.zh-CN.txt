 一块贴在屏幕正上方的小卡片，显示：

     - 现在几点、星期几
     - 现在第几节、上什么课
     - 还有多久下课 / 多久上课
     - 正在上课时，底部有一条细进度条

 它永远压在别的窗口上面；一放 PPT 或者全屏视频就自己藏起来；
 按住鼠标左键可以随便拖。

 只用 Python 标准库写成。不用安装、不写注册表、不联网、不弹黑框，
 运行期间一个文件都不写。

 完整文档：README.zh-CN.md（中文）  /  README.md（英文）


------------------------------------------------------------------------------
 这个文件夹里有什么
------------------------------------------------------------------------------

   桌面时钟.exe     时钟本体，双击这个就行            （不需要装 Python）
   转换课表.exe     把 .xlsx 课表转成 schedule.json    （不需要装 Python）
   开机自启.exe     开关开机自启的小面板               （不需要装 Python）

   clock.pyw        时钟本体（源码版）                 （需要 Python）
   convert.py       转换脚本（源码版）                 （需要 Python + openpyxl）
   开机自启.pyw      自启面板（源码版）                 （需要 Python）
   转换课表.bat      跑 convert.py 的小脚本            （需要 Python）

   schedule.json    课表数据，时钟只读它
   时钟.ico          程序图标


------------------------------------------------------------------------------
 怎么用
------------------------------------------------------------------------------

   不用装任何东西：

       1. 双击「桌面时钟.exe」
       2. 好了。卡片会出现在屏幕正上方居中。

   想移动它：  按住鼠标左键拖，拖到哪儿就是哪儿。
   想关掉它：  在卡片上点右键 -> 退出


------------------------------------------------------------------------------
 右半边那些字是什么意思
------------------------------------------------------------------------------

   那个小圆点：

       绿色    正在上课（会轻轻呼吸）
       橙色    下一节 30 分钟内开始
       灰色    课间 / 暂时没课

   上面那行字，按这个顺序判断：

       1. 现在落在有科目的时段里       ->  第3节 语文
       2. 现在落在没科目的时段里       ->  课间 / 午饭 / 眼保健操
       3. 都没命中，但下一节 30 分钟内 ->  下节：体育
       4. 都没命中                     ->  课间休息

   下面那行倒计时：

       距上课25分 · 距下课18分    正在上课，后面还有课
       距下课18分                 正在上课，当天最后一节
       距上课8分                  课间，知道下一节
       今天没课了                 今天的课上完了
       （空着）                   课表文件缺失或者坏了

   底部那条绿色细线只在真正上课的时候出现，按这节课已经过去的比例填充。


------------------------------------------------------------------------------
 怎么换课表
------------------------------------------------------------------------------

   不装 Python：

       1. 把新课表存成 .xlsx。第 1 行是表头：
          空一格，然后 MON / TUE / WED / THR / FRI，最后一列是「时间」。
          从第 2 行开始，一行一个时段：
          节次名、五天的科目、最后一个时间区间（比如 8:00-8:40）。

       2. 把文件放进这个文件夹，命名成「课程表.xlsx」会被自动认出来；
          或者双击「转换课表.exe」自己挑那个文件。

       3. schedule.json 会生成在 exe 旁边。正在跑的时钟 10 秒内自动读新的，
          不用重启。

   装了 Python：

       在命令行里执行   python convert.py 路径\课程表.xlsx


------------------------------------------------------------------------------
 开机自启
------------------------------------------------------------------------------

   双击「开机自启.exe」，点一下「开启开机自启」按钮就行。

   程序不碰注册表，只在当前用户的「启动」文件夹里增加 / 删除一个快捷方式：

       %APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup\桌面时钟.lnk

   也支持命令行：

       开机自启.exe --install     打开
       开机自启.exe --remove      关闭
       开机自启.exe --status      返回码 0 = 已开启，1 = 未开启

   要是把这个文件夹搬到了别的地方，记得重新跑一次 --install，
   让快捷方式指向新位置。


------------------------------------------------------------------------------
 时钟不见了怎么办
------------------------------------------------------------------------------

   先看是不是正在放 PPT 或者全屏视频。那种时候它是故意藏起来的，
   退出全屏 1.5 秒内就会回来。除此以外它每 5 秒自检一次置顶状态。

   想彻底关掉「全屏自动隐藏」，把 clock.pyw 顶部的
   AUTO_HIDE_ON_FULLSCREEN 改成 False
   （只对源码版生效，打包版要改完重新打包）。


------------------------------------------------------------------------------
 想改外观
------------------------------------------------------------------------------

   所有能调的东西都在 clock.pyw 顶部的一段「可调参数」里，中文注释写得很清楚：
   尺寸、颜色、字体、刷新间隔、「快上课」的 30 分钟提前量等等。

   改 clock.pyw 只影响源码版。要让打包的 .exe 也变，得改完源码重新打包，
   打包命令见 README.zh-CN.md 的「自己打包 exe」一节。


------------------------------------------------------------------------------
 关于杀毒软件误报
------------------------------------------------------------------------------

   源码版（clock.pyw）没什么可疑的。

   exe 是 PyInstaller 单文件模式打的，它本身是个自解压包：启动时先把
   Python 和 Tk 解压到 %TEMP% 再运行。有些杀软会对这个特征报警。
   万一被拦了，可以把整个文件夹加进白名单，或者改用源码版，
   或者自己打一个 --onedir 的文件夹版。


------------------------------------------------------------------------------
 彻底卸载
------------------------------------------------------------------------------

   1. 在卡片上点右键 -> 退出
   2. 运行「开机自启.exe」把开机自启关掉（或者 --remove）
   3. 把这个文件夹删掉
